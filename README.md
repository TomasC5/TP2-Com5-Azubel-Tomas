<h1>TP2-Portfolio V2</h1>

My name is Azubel Tomas, this project contains a Portfolio made with React JS to showcase my current skills in programming made in Visual Studio Code.

<h2>INSTALL GUIDE</h2>

   1) Download the ZIP file containing this project
   2) Extract the ZIP file wherever you like
   3) Install Node.js (LTS version + default options)
   4) Verify installation by opening CMD in admin mode and run: node -v npm -v
   5) Install Visual Studio Code (make sure to enable "Add to PATH")
   6) Launch VSCode
   7) Drag and drop the project folder to VSCode
   8) Install the project's dependencies with Terminal -> New Terminal
   9) Run: cd ./portfolioV2
   10) Run: npm install
   11) Run: npm run dev
   12) Ctrl + Click on the Local link shown in the terminal (typically http://localhost:5173/) to see the project result
